# Poornima Attendance Management System (PAMS) - Project Handover

## 1. Project Overview
**Name:** Poornima Attendance Management System (PAMS)
**Institute:** Poornima Institute of Engineering and Technology, Jaipur
**Type:** Web Application (Vanilla HTML/CSS/JS)
**Goal:** To provide a centralized digital system for managing student attendance, academic data, and institutional operations.

## 2. Architecture & Tech Stack
- **Frontend Core:** Vanilla HTML5, CSS3, JavaScript (ES6+).
- **Libraries/Assets:**
  - Lucide Icons (CDN)
  - Chart.js (CDN)
  - Google Fonts: Inter
- **Backend/Data Layer (Hybrid Approach):**
  - **Mock Data Engine:** Used for Admin and Faculty. Uses `DataStore` to persist mock data in `localStorage` across reloads.
  - **Firebase Integration (Phase 7):** Used for **Student Authentication**. Includes Firebase v10 Compat SDK (App, Auth, Firestore).

## 5. How to Run the Project
1. Since the project uses plain HTML/JS and relies on Firebase Authentication (which requires `http` or `https` instead of `file://`), you must serve the directory using a local web server.
2. A PowerShell script (`server.ps1`) is provided to start a local HTTP server.
3. Open `http://localhost:5000` (or whichever port the server uses) in your browser.
4. **Admin/Faculty Login:** Select the respective role and use the pre-filled mock credentials (password: `password123`).
5. **Student Login:** Select the Student role and use the "Continue with Google" button to authenticate via Firebase.
